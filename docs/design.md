# TenderTruck Design Tokens

## Typography

- Primary: IBM Plex Sans
- Monospace/data: IBM Plex Mono

## Color

- Graphite base: `#202124`
- Secondary graphite: `#5F6368`
- Action accent: `#D9480F`
- Surface: `#FFFFFF`
- Border: `#D5D7DA`

## Shape and Layout

- Border radius: 6px
- Prefer visible 1px borders over shadows.
- Use Lucide icons.

## Restrictions

- No emojis.
- No gradients.
- No purple branding.
- No hero sections.
