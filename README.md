# TenderTruck

Сервис автоматизации тендерных грузоперевозок. Текущая версия реализует базовую регистрацию и авторизацию компаний, личный кабинет и редактирование профиля. Торги, заявки, рейсы, документы и администрирование остаются следующими этапами разработки по ТЗ.

## Запуск через Docker Compose

1. Скопируйте `.env.example` в `.env` и задайте собственный `SECRET_KEY` и пароль PostgreSQL.
2. Из корня репозитория выполните `docker compose up --build`.
3. Откройте `http://localhost` (или порт из `WEB_PORT`). API доступно на `http://localhost:8000`, документация — `/docs`.

При запуске backend применяет миграции Alembic. PostgreSQL запускается с проверкой готовности до старта backend. Данные БД хранятся в Docker volume `postgres_data`.

## Локальная разработка

Backend: установите зависимости из `requirements.txt`, настройте `DATABASE_URL` и `SECRET_KEY`, затем выполните `alembic upgrade head` и `uvicorn app.main:app --reload`.

Frontend: в каталоге `web` выполните `npm ci` и `npm run dev`. Vite проксирует `/api` на `http://localhost:8000`. Для работы без backend можно включить `VITE_USE_MOCKS=true` в `web/.env`; моковый режим предназначен только для локальной разработки.

## Текущие API маршруты

- `POST /api/v1/auth/register` — регистрация заказчика или перевозчика.
- `POST /api/v1/auth/login` — получение bearer-токена.
- `GET /api/v1/users/me` — просмотр профиля текущего пользователя.
- `PUT /api/v1/users/me` — изменение редактируемых полей профиля.

Для локальной конфигурации используйте `.env.example` как шаблон. Не публикуйте `.env` и не используйте демонстрационные пароли/ключи в развернутой системе.
